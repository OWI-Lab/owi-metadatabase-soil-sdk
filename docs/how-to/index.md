# How-to Guides

How-to guides are **problem-oriented** — each one solves a specific task
with a minimum of background explanation.

| Guide | What it covers |
|-------|----------------|
| [Install the SDK](install.md) | Install `owi-metadatabase-soil` standalone or as a core extra. |
| [Authenticate](authenticate.md) | Obtain and configure your API token. |
| [Query Soil Entities](query-entities.md) | List, filter, and retrieve any soil entity type. |
| [Process CPT Data](process-cpt.md) | Transform raw CPT payloads into Groundhog objects. |
| [Build Soil Profiles](build-profiles.md) | Convert profile details into Groundhog `SoilProfile` objects. |
| [Prepare SSI Input](prepare-ssi-input.md) | Validate and format soil profiles for SSI analysis methods. |
| [Plot Soil Data](plot-soil-data.md) | Render test location maps and fence diagrams. |
